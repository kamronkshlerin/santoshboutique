# 🪡 Santosh Boutique & Stitching Studio

> **LADIES FASHION | CUSTOM STITCHING | STYLE FOR EVERY YOU**  
> *Near Baba Balak Nath Temple, Sarti, Bilaspur (H.P.) 174004*

An ultra-luxurious, motion-first digital experience and interactive bespoke tailoring web application built for **Santosh Boutique & Stitching Studio**. Designed to the benchmark standards of **motionsites.ai**.

---

## ✨ Key Features

- **Cinematic Ambient Hero**: High-contrast editorial luxury typography (*Playfair Display* + *Plus Jakarta Sans*), animated gold embroidery thread and dust particles canvas simulation.
- **5 Core Atelier Services**:
  - 👗 **Suit & Kurti Stitching**: Punjabi Patiala, straight pants, Anarkalis
  - 🥻 **Designer Blouse**: Princess cut, deep back with dori/latkans, bridal handwork
  - ⚡ **Alteration Services**: Precision 24h express fitting & repairs
  - ✂️ **Custom Tailoring**: Pinterest & Instagram photo recreations
  - ✨ **Lehenga & Party Wear**: Bridal 16-kalidar flare, can-can padding, dupatta finishing
- **Interactive Style & Measurement Configurator**: Live quotation calculation and direct 1-click structured WhatsApp booking payload engine.
- **Before & After Alteration Split Slider**: Interactive scissors slider comparing loose readymade garments vs. bespoke contoured fit.
- **Filterable Lookbook Gallery**: Bridal couture, suits, and designer blouses with modal zoom.
- **Hyperlocal Trust & Landmark Navigation**: Real photos of the boutique shop exterior and the iconic Baba Balak Nath Temple 3-dome arch gate in Sarti, with one-tap Google Maps GPS navigation.
- **Floating WhatsApp Engine**: Always-accessible direct booking trigger.

---

## 🛠️ Tech Stack

- **Framework**: React 18 + Vite + TypeScript
- **Styling**: Tailwind CSS v4 + Vanilla CSS Design Tokens (`.liquid-glass`)
- **Icons**: `lucide-react`
- **SEO**: Embedded `LocalBusiness` JSON-LD Schema (Bilaspur 174004)

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
